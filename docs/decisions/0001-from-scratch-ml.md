# ADR 0001: From-scratch ML

## Context

I want to understand how training, gradients and neural networks work instead of just using a finished tool.

## Decision

I will first implement autograd and a small neural network from scratch.

## Consequences

I will compare it with simple baseline models like logistic regression and other rule-based approaches. This may be less accurate or slower than using an ML library, but it will help me understand the training process.
